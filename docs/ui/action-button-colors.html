Action colors — 3 options

Each action keeps the same color everywhere: the + Add buttons and the Action cell of each step row. Click = cyan, Key = pink, Text = green, Wait = amber, Wheel = blue (from the app theme's role colors), each with its own icon.

Option 1 — Tinted

Soft colored background, colored text and border. Readable and calm; colors identify actions without dominating the table. Hover fills the button solid.
