Macro editor — 3 layout options

Each option fixes the same problems in the current editor: the Record point button sits far from X, Y; ✓/✕ icons have no labels; Coordinates is buried below; the big empty area; and Repeat/Interval (ms) differs from the Profiles row's Loop toggle and Interval (s).

A · Inline table B · Step cards + inspector C · Timeline

Option A — Inline table (edit in the row)

No side panel. Each step is edited directly in its row: type, X/Y, Record, Wait after. Changes save on Enter or when the field loses focus, so there's no ✓/✕. Best for long macros and quick edits.

Option B — Step cards + focused inspector

Closest to today, but tidier. Steps become compact cards with a colored type badge and their wait. The right inspector groups everything for the selected step: type as segmented buttons, X and Y with a big Record button, Wait after. Edits auto-save (a small "Saved" note replaces ✓/✕).

Option C — Timeline

Shows timing visually. Steps are blocks on a left-to-right line, with each wait drawn as the gap between them and a loop-back marker at the end. Selecting a block opens a small editor panel below. Best for short click loops like CookieRun farming; less suited to 20+ steps.
